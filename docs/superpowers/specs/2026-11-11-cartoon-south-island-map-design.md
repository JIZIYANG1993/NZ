# 卡通新西兰南岛路线底图设计

## 意图
将当前路线总览中的模板底图替换为一张适合手机和电脑查看的卡通新西兰南岛插画，让用户能直观看到南岛形状、主要自然区域和旅行方向，同时保留网页现有路线、日期图例、地点标记和点击交互。

## 目标
- 生成一张横向、浅色、低细节但可辨识的新西兰南岛卡通底图。
- 底图只表达南岛轮廓、山脉、湖泊、海岸和少量地理装饰，不绘制本次路线线条、日期或地点文字。
- 将底图作为本次旅行的 trip-specific asset 接入页面，现有路线数据继续由网页叠加。
- 保持手机端可读、电脑端可放大查看，并保留当前地图免责声明。

## 非目标
- 不改变日期、路线顺序、地点坐标、Google Maps 导航或每日行程。
- 不把餐厅、门票或营地添加到总览地图。
- 不发布公网版本。

## 方案
1. 卡通南岛底图 + 网页路线叠加（已选择）：可维护性最好，后续改行程不需要重画路线。
2. 整张地图一次生成：视觉完整，但路线变更需要重做整图。
3. SVG/CSS 网页插画：可编辑，但卡通质感和自然细节较弱。

## 实施决定
- 使用内置图片生成工具生成 PNG 底图，保存为旅行页面的 trip-specific asset。
- 生成图不包含文字、路线和彩色日期标记，避免与网页叠加层重复。
- 在地图渲染源中加入本次旅行的底图引用；不修改通用地图模板素材。
- 重新构建地图、运行数据校验，并检查本地预览页面的地图显示。

## 验收
- 页面显示南岛卡通底图，而不是当前抽象模板底图。
- 路线、地点标记、日期图例仍然可见。
- `npm run build:map` 和 `npm run validate` 通过。
- 本地预览 HTTP 200，手机端地图可滚动或放大查看。
